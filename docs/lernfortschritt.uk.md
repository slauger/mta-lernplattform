# Як я документую свій прогрес у навчанні {#wie-ich-meinen-lernfortschritt-dokumentiere}

## Навіщо документувати прогрес? {#warum-fortschritt-dokumentieren}

Документування прогресу в навчанні (Lernfortschritt) допомагає тобі:

- ✅ **Мотивація**: ти бачиш, чого вже досяг!
- ✅ **Структура**: ти не втрачаєш загальної картини
- ✅ **Виявлення прогалин**: ти бачиш, що ще треба допрацювати
- ✅ **Підготовка до іспиту**: ти знаєш, що треба повторити

!!! success "Порада"
    Щонеділі виділяй **15 хвилин**, щоб оновити свій прогрес!

---

## Метод 1: чек-листи (простий) {#methode-1-checklisten-einfach}

### Загальний чек-лист {#gesamt-checkliste}

Використовуй цей чек-лист, щоб відстежувати свій прогрес за всіма розділами:

#### Вступ {#einfuhrung}

- [ ] Прочитав «Вступ і орієнтація» (Einführung & Orientierung)
- [ ] Опрацював «Терміни та скорочення» (Begriffe & Abkürzungen) (вивчив щонайменше 50 термінів)

#### Теорія {#theorie}

- [ ] Зрозумів цілі, завдання та цінності (Ziele, Aufgaben & Werte)
- [ ] Зрозумів горіння та гасіння (Brennen & Löschen) (класи пожеж, засоби гасіння)
- [ ] Знаю автомобілі та обладнання (Fahrzeuge & Geräte) (LF, HLF, засоби індивідуального захисту – PSA)
- [ ] Вивчив правові основи та безпеку (Rechtsgrundlagen & Sicherheit) (BayFwG, UVV, GAMS)
- [ ] Зрозумів виклик і радіозв'язок (Einsatz & Funk) (перебіг виклику, радіоповідомлення – Funksprüche)

#### Практика {#praxis}

- [ ] Впевнено в'яжу Mastwurf (вибленочний вузол) накладанням і обвиванням (горизонтально + вертикально)
- [ ] Впевнено в'яжу Zimmermannsschlag (теслярський вузол)
- [ ] Впевнено в'яжу Pfahlstich + Spierenstich (Brustbund – грудна обв'язка) на людині
- [ ] Володію Schotenstich (шкотовий вузол: простий, подвійний, із петлею для розв'язування), Halbschlag (напівштик), Halbmastwurf (напіввибленочний вузол)
- [ ] Почав фітнес-тренування (щонайменше 2 рази на тиждень)
- [ ] Опрацював список матеріалів (Materialliste) (тренувальна мотузка, підручник)

#### Підготовка до іспиту {#prufungsvorbereitung}

- [ ] Відповів щонайменше на 50 питань до іспиту
- [ ] Відповів щонайменше на 100 питань до іспиту
- [ ] Відповів на всі 274 питання до іспиту (214 базовий модуль + 60 командир ланки – Truppführer)
- [ ] Повторив питання, на які відповів неправильно

#### Goldkronach {#goldkronach}

- [ ] Прочитав розділ про Goldkronach
- [ ] Поговорив із командиром (Kommandant) про місцеві автомобілі
- [ ] Пройшов екскурсію пожежним депо (Gerätehaus)

#### Ресурси {#ressourcen}

- [ ] Купив / позичив підручник
- [ ] Спробував Feuerwehr-Lernbar
- [ ] Підписався на YouTube-канали
- [ ] Прочитав FwDV 3

### Трекер розділів {#kapitel-tracker}

Для кожного теоретичного розділу:

**Приклад: горіння та гасіння (Brennen & Löschen)**

| Тема | Прочитав | Зрозумів | Тест складено | Треба повторити? |
|-------|---------|-----------|----------------|---------------------|
| Трикутник горіння (Verbrennungsdreieck) | ✅ | ✅ | ✅ | Ні |
| Класи пожеж A-F (Brandklassen) | ✅ | ✅ | ❌ (лише 60%) | Так, повторити клас D + F |
| Засоби гасіння (Löschmittel) | ✅ | ⚠️ (частково) | ❌ | Так, дія піни незрозуміла |
| Фази пожежі (Brandphasen) | ✅ | ✅ | ✅ | Ні |
| Backdraft (вибух диму) | ✅ | ⚠️ | ❌ | Так, вивчити ознаки |

**Легенда:**

- ✅ = так / добре
- ⚠️ = частково / нормально
- ❌ = ні / погано

## Метод 3: Git/GitHub (для тих, хто дружить з технікою) {#methode-3-gitgithub-fur-technik-affine}

Якщо ти знайомий із Git, можеш відстежувати свій прогрес у цьому репозиторії!

### Крок 1: ініціалізувати репозиторій {#schritt-1-repo-initialisieren}

```bash
cd ~/mta-lernen
git init
git add .
git commit -m "Initial commit: MTA Lernmaterial"
```

### Крок 2: створити файл прогресу {#schritt-2-lernfortschritt-datei-anlegen}

Створи файл `LERNFORTSCHRITT.md`:

```markdown
# Мій прогрес у навчанні

## Тиждень 1 (01.01.-07.01.2026)

- ✅ Прочитав вступ
- ✅ Відпрацював Mastwurf 20x
- ⏳ Вивчаю класи пожеж (у процесі)

## Тиждень 2 (08.01.-14.01.2026)

- ✅ Вивчив класи пожеж A-F
- ✅ Відпрацював Zimmermannsschlag 15x
- ❌ Фітнес: лише 1x біг (мета: 3x) → наступного тижня краще!
```

### Крок 3: регулярно робити коміти {#schritt-3-regelmaig-committen}

```bash
git add LERNFORTSCHRITT.md
git commit -m "Woche 2: Brandklassen gelernt, Knoten geübt"
```

**Перевага:** у тебе є повна історія твого прогресу в навчанні!

## Метод 4: цифрові інструменти {#methode-4-digitale-tools}

### Notion / Obsidian {#notion-obsidian}

- Створи базу даних з усіма темами
- Познач статус (Todo / In Progress / Done)
- Пов'язуй нотатки між собою посиланнями

### Trello / Kanban-дошка {#trello-kanban-board}

- **Todo**: теми, які ще треба вивчити
- **In Progress**: те, що ти зараз вивчаєш
- **Done**: те, що ти вже завершив

**Приклад дошки:**
```
| Todo                  | In Progress          | Done                    |
|-----------------------|----------------------|-------------------------|
| - Автомобілі          | - Класи пожеж        | - Mastwurf              |
| - Радіоповідомлення   | - Фітнес 3x/тиж      | - Прочитав вступ        |
| - Питання до іспиту   |                      | - Терміни (50 штук)     |
```

### Таблиця (Excel / Google Sheets) {#spreadsheet-excel-google-sheets}

Створи таблицю, як вище (тижневий трекер), але в цифровому вигляді → так її легше оновлювати!

## Метод 5: трекер питань до іспиту {#methode-5-prufungsfragen-tracker}

Відстежуй, на які питання до іспиту (Prüfungsfragen) ти відповів правильно чи неправильно:

| № питання | Тема | Правильно? | Дата | Повторити? |
|-----------|-------|----------|-------|---------------|
| 1 | Цілі та завдання (Ziele & Aufgaben) | ✅ | 05.01. | Ні |
| 6 | Горіння та гасіння (Brennen & Löschen) | ❌ | 05.01. | Так, 12.01. |
| 7 | Горіння та гасіння (Brennen & Löschen) | ✅ | 05.01. | Ні |
| ... | ... | ... | ... | ... |

**Правило повторення:** питання з неправильною відповіддю повторюй через **1 день, 3 дні, 7 днів**!

## Метод 6: щоденник навчання {#methode-6-lerntagebuch}

Веди щоденник навчання (Lerntagebuch) – від руки або в цифровому вигляді:

**Приклад запису:**

```
Дата: 10.01.2026
Тривалість: 2 години

Що я сьогодні вивчив?

- Класи пожеж A-F
- Різниця між рятуванням (Retten) і евакуацією тіл/майна (Bergen)
- Відпрацював Mastwurf 10x

Що вдалося?

- Клас пожежі A+B зрозумів одразу
- Mastwurf менш ніж за 10 секунд!

Що не вдалося?

- Клас пожежі D (метали) ще незрозумілий
- Zimmermannsschlag ще займає забагато часу (40 сек.)

Що роблю завтра?

- Ще раз прочитати клас пожежі D
- Відпрацювати Zimmermannsschlag 20x
- 30 хв бігу
```

## Міні-чек-листи для кожного розділу {#mini-checklisten-pro-kapitel}

### Розділ: горіння та гасіння (Brennen & Löschen) {#kapitel-brennen-loschen}

- [ ] Зрозумів трикутник горіння (Verbrennungsdreieck)
- [ ] Вивчив усі 5 класів пожеж (A, B, C, D, F)
- [ ] Знаю засоби гасіння для кожного класу пожежі
- [ ] Знаю, чому НІКОЛИ не можна лити воду на жир
- [ ] Знаю, чому НІКОЛИ не можна лити воду на метали
- [ ] Знаю 3 способи гасіння (Löschverfahren): охолодження (Abkühlen), задушення (Ersticken), видалення (Beseitigen)
- [ ] Знаю ознаки Backdraft (вибуху диму)
- [ ] Склав тест із цього розділу (щонайменше 80%)

### Розділ: автомобілі та обладнання (Fahrzeuge & Geräte) {#kapitel-fahrzeuge-gerate}

- [ ] Знаю різницю між TSF, LF, TLF, HLF
- [ ] Знаю, що LF 20 розрахований на 9 осіб
- [ ] Знаю рукав B (B-Schlauch, 75 мм) і рукав C (C-Schlauch, 42/52 мм)
- [ ] Можу перелічити складові засобів індивідуального захисту (PSA) (6 частин)
- [ ] Знаю, на скільки вистачає дихального апарата (PA) (20-30 хв)
- [ ] Знаю різницю між всмоктувальним рукавом (Saugschlauch) і напірним рукавом (Druckschlauch)
- [ ] Склав тест із цього розділу (щонайменше 80%)

(... для всіх розділів)

## Поради, як не здатися {#tipps-zum-durchhalten}

### 1. Став реалістичні цілі {#1-realistische-ziele-setzen}

**Погано:** «Цього тижня я вивчу все!»

**Добре:** «Цього тижня я вивчу класи пожеж + тричі відпрацюю Mastwurf»

### 2. Маленькі кроки {#2-kleine-schritte}

**Краще 15 хвилин щодня**, ніж 3 години в неділю!

### 3. Винагороди {#3-belohnungen}

Після кожного завершеного тижня: улюблена страва, фільм тощо.

### 4. Партнер для навчання {#4-lernpartner}

Знайди колегу з MTA і вчіться разом! Ви можете перевіряти одне одного.

### 5. Розпорядок {#5-routine}

Фіксований час для навчання (напр. щодня 19:00-19:30) допомагає не збавляти темп.

## Твій особистий план навчання (приклад) {#dein-personlicher-lernplan-beispiel}

### 4 тижні до початку MTA {#4-wochen-bis-mta-start}

| Тиждень | Фокус | Цілі |
|-------|-------|-------|
| **1** | Вступ + терміни + вузли | - Прочитав вступ<br>- Вивчив 30 термінів<br>- Впевнено в'яжу Mastwurf + Halbschlag + Spierenstich (контрольний вузол) |
| **2** | Теорія: горіння та гасіння + автомобілі | - Вивчив класи пожеж<br>- Знаю типи автомобілів<br>- Впевнено в'яжу Zimmermannsschlag |
| **3** | Теорія: право + виклик + фітнес | - Вивчив BayFwG, UVV, GAMS<br>- Зрозумів перебіг виклику<br>- 3x фітнес |
| **4** | Підготовка до іспиту | - Відповів на всі 274 питання<br>- Повторив питання з неправильними відповідями<br>- Довів вузли до досконалості |
