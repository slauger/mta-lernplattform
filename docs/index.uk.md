# 🚒 Підготовка до MTA {#mta-vorbereitung}

## Добровільна пожежна команда Гольдкронах (Freiwillige Feuerwehr Goldkronach) {#freiwillige-feuerwehr-goldkronach}

Повні навчальні та тренувальні матеріали для **модульної підготовки ланки (MTA, Modulare Truppausbildung)** у Баварії.

!!! info "Українська версія"
    Увесь сайт, включно з тестом, доступний українською. Курс та іспит проходять **німецькою мовою**, тому в перекладі важливі терміни завжди подано також німецькою в дужках, а в тесті під кожним питанням є німецький оригінал. Переклад неофіційний – чинними є німецькі матеріали.

    Перемикати мову можна вгорі сторінки (значок мови).

!!! info "Для кого це?"
    Ці матеріали призначені для **початківців без попередніх знань**, які хочуть підготуватися до MTA. Створено спеціально для членів FF Goldkronach, але ними можуть користуватися всі учасники MTA в Баварії.

## 💡 Рекомендований шлях навчання {#empfohlener-lernpfad}

!!! tip "Для початківців (4–6 тижнів підготовки)"

    **Тиждень 1–2**: зрозуміти основи

    1. Прочитати [Вступ і орієнтацію](einfuehrung.md)
    2. Опрацювати [Терміни та скорочення](begriffe.md) (щонайменше 50 термінів)
    3. Теоретичні розділи: [Цілі та завдання](theorie/ziele-aufgaben.md) + [Горіння та гасіння](theorie/brennen-loeschen.md)

    **Тиждень 3–4**: поглибити теорію + почати практику

    4. Теоретичні розділи: [Автомобілі та обладнання](theorie/fahrzeuge-geraete.md) + [Правові основи](theorie/recht-sicherheit.md)
    5. [Тренувати вузли](praxis/knoten.md) (Mastwurf, Zimmermannsschlag)
    6. Почати [фітнес-тренування](praxis/uebungen-fitness.md) (2–3 рази на тиждень)

    **Тиждень 5–6**: підготовка до іспиту + вдосконалення

    7. [Переглянути всі питання](quiz/browse.html) для навчання
    8. Проходити [інтерактивний тест](quiz/index.html) (кілька разів!)
    9. Відпрацювати вузли до досконалості (на час)
    10. Документувати [прогрес навчання](lernfortschritt.md)

## ⚠️ Важливі зауваження {#wichtige-hinweise}

!!! warning "Безпека понад усе"

    - **Не проводь небезпечних експериментів** удома
    - **Не використовуй справжній вогонь** для тренувань із гасіння
